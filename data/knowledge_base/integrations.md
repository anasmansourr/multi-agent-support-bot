# Integrations

Slack: sends task notifications to a channel. Connect it under Settings > Integrations. If it disconnects, a Slack workspace admin may have revoked access; reconnect it and approve the permissions.

Google Calendar: two-way sync of due dates. If events appear twice, two calendars are connected; disconnect both and connect once.

GitHub: link commits and pull requests to tasks.

Not available: Microsoft Teams, Jira and Trello. A Zapier integration is under review.

Data can be brought in from other tools by CSV import only. There is no direct import from Trello or Asana.
