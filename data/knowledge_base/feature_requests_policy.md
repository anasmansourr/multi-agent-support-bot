# Feature requests and roadmap

Customers can send feature requests to support. The product team reviews them every month. Votes help decide priorities.

Statuses: under review, planned, in progress, shipped and not planned. A date is a target, not a promise.

Roadmap as of October 2026:
- Shipped: kanban board view, CSV import and export, Slack and GitHub integrations.
- In progress: SAML single sign-on, target Q4 2026.
- Planned: dark mode (Q1 2027), recurring tasks (Q2 2027).
- Under review: Excel export, Zapier integration.
- Not planned: offline mode.
